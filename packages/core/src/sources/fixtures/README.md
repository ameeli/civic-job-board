These are trimmed excerpts of saved source pages and API responses, used only
by the source adapter tests. They are not shipped with the app. The tests use
fake HTTP responses and never follow these links on the network.

The original job links, feed identifiers, dates, and relevant markup are kept
so tests exercise the real source formats, URL normalization, and job identity.
Descriptions retain short verbatim excerpts rather than full postings. Scripts,
styles, navigation, unrelated jobs, and unused fields have been removed, except
for the embedded job record and apply-link handler that the adapters parse.

The samples retain premium-only sitemap entries (to check they are not fetched),
DSCovery highlighted duplicates and feed-only jobs, and newsletter section and
old-issue examples. The Civic Tech Field Guide excerpts are attributed to the
[Civic Tech Field Guide](https://civictech.guide), licensed
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
